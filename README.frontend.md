# AgriTwin AI Frontend

A React + Vite frontend for AgriTwin AI, a precision agriculture dashboard demo.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start development server:
   ```bash
   npm run dev
   ```

## Features

- React Router navigation
- Recharts data visualization
- Leaflet map integration
- Mock data architecture for future API connection
- Responsive agriculture dashboard UI
